§1 Vocabulário: de caracteres únicos a índices

Corpus de exemplo: "abacate". Caracteres únicos ordenados alfabeticamente viram índices 0..vocabSize-1. charToIdx e idxToChar são o mesmo mapeamento, nos dois sentidos.

FIG 1 charToIdx = {a:0, b:1, c:2, e:3, t:4}, vocabSize = 5. A ordem alfabética é o que torna o mapeamento reproduzível entre execuções.

§2 A janela desliza, o target é a mesma janela +1

contextLength = 4 sobre o corpus codificado [0,1,0,2,0,4,3] ("abacate"), começando em start = 0. O target não é uma janela nova — é a linha de input inteira, deslocada uma casa pra direita.

FIG 2 O par (input, target) exige contextLength+1 tokens consecutivos do corpus — por isso o intervalo válido de start é um a menos que o ingênuo 0 até corpusLength-contextLength.

§3 Batch: várias janelas independentes empilhadas

B posições start amostradas de forma independente (não precisam ser vizinhas nem ordenadas) viram B linhas de um tensor (B, contextLength).

FIG 3 As duas linhas não têm relação entre si além de virem do mesmo corpus — B=2, contextLength=4, shape final (2,4) pros inputs e pros targets.
